# Glazok Studio для Windows

Пульт Glazok в отдельном окне и **виртуальные камеры** для OBS и vMix: телефон добавляется
как обычная камера, без браузерного источника.

| Камера | Что показывает |
|---|---|
| **Glazok Program** | телефон, который сейчас в эфире (переключается в пульте) |
| **Glazok Cam 1…4** | телефон, которому в пульте назначена эта камера («Камера в OBS/vMix») |

Камеры отдают 1920×1080 (также 1280×720 и 3840×2160), 30 кадров/с. Вертикальное видео вписывается с полями.
Пока программа открыта, а сигнала нет, камера чёрная; если программа закрыта — заставка «Нет сигнала».
Звук в виртуальную камеру не передаётся.

## Установка

1. GitHub → **Actions** → **Windows app** → последний запуск → артефакт **Glazok-Studio-Windows**.
2. Распакуйте zip и запустите `GlazokStudio-Setup-*.exe`. Права администратора не нужны:
   программа и камеры ставятся только для текущего пользователя.
   Windows может предупредить о неизвестном издателе (установщик не подписан): «Подробнее → Выполнить в любом случае».
3. Запустите **Glazok Studio**, затем перезапустите OBS/vMix, если они были открыты.
4. OBS: «Устройство захвата видео» → Glazok Program / Glazok Cam N. vMix: Add Input → Camera.

## Как пользоваться

1. Отсканируйте QR в Glazok Studio телефоном (приложение для iPhone или страница телефона на Android).
2. В карточке телефона выберите «Камера в OBS/vMix» → Glazok Cam N. Такой телефон передаёт видео
   постоянно; переключать камеры можно прямо в OBS/vMix.
3. «Запустить эфир» / «Переключить сюда» — меняет то, что показывает Glazok Program.

## Устройство

| Папка | Что это |
|---|---|
| `vcam/` | Драйвер камеры: источник DirectShow (C++, DirectShow BaseClasses от Microsoft, MIT). Кадры берёт из общей памяти `GlazokVCam_N`, формат — `vcam/shared.h` |
| `vcam/tools/` | `glazok-grab` — список камер и снимок кадра; `glazok-testpattern` — тестовая картинка в камеру |
| `app/` | Electron: открывает пульт с GitHub Pages, регистрирует камеры в HKCU и пишет в них кадры (`preload.js`, `vcam.js`) |

Сборка на своём ПК (Visual Studio с C++ и Node.js):

```powershell
cmake -S windows/vcam -B windows/vcam/build -A x64; cmake --build windows/vcam/build --config Release
cd windows/app; npm ci; npm start          # запуск без установки
npx electron-builder --win nsis            # установщик в windows/app/dist
```

Чтобы проверить пульт до публикации на GitHub Pages: `$env:GLAZOK_URL="http://127.0.0.1:8090/monitor.html"; npm start`.
