# Glazok для iPhone

Отдельное приложение-камера для iPhone. Подключается к тому же монитору (`monitor.html`)
по тому же QR-коду, но, в отличие от Safari, даёт полный доступ к камере:

- **фокус по точке** — нажмите на картинку на телефоне или кликните по видео на мониторе;
- кнопка «Фокус: точка ✕» возвращает обычный автофокус;
- **ручная камера**: баланс белого (K), ISO, выдержка, экспокоррекция, ручная дистанция фокуса —
  на телефоне (кнопка «Ручной») и со слайдеров на мониторе;
- **объективы** 0.5× / 1× / теле, оптический зум (щипок или слайдер), фонарик;
- эфир по команде монитора, прямая отдача в Clean Output (vMix/OBS), TURN из QR-кода.

Веб-версия (`index.html`) продолжает работать как раньше — для Android и как запасной вариант.

## Как получить приложение (Mac не нужен)

Приложение собирает GitHub на своём Mac-сервере.

1. Отправьте изменения на GitHub (`git push`). Сборка запускается сама при изменениях в папке `ios/`;
   вручную — вкладка **Actions** → **iOS app** → **Run workflow**.
2. Через ~10 минут откройте завершённый запуск и скачайте артефакт **Glazok-iOS** (zip с `Glazok.ipa`).
3. Установите на iPhone с компьютера на Windows через **Sideloadly** (sideloadly.io):
   - подключите iPhone кабелем, в iTunes/«Устройства Apple» нажмите «Доверять»;
   - перетащите `Glazok.ipa` в Sideloadly, введите свой Apple ID и нажмите **Start**.
4. На iPhone: **Настройки → Конфиденциальность и безопасность → Режим разработчика → Вкл**
   (iOS 16+, телефон перезагрузится), затем **Настройки → Основные → VPN и управление устройством** →
   доверьте свой Apple ID.

**Важно про бесплатный Apple ID:** приложение работает 7 дней, потом его нужно переустановить
тем же способом (Sideloadly умеет делать это автоматически, если компьютер и телефон в одной сети).
С платным аккаунтом разработчика Apple (99 $/год) — год, и можно раздать через TestFlight.

## Как пользоваться

1. На компьютере откройте монитор, на iPhone — приложение Glazok.
2. «Сканировать QR-код» → наведите на QR монитора. Приложение подключится само.
3. На мониторе выберите телефон и нажмите «Запустить эфир».
4. Нажмите на картинку там, на чём нужен фокус (или кликните в это место видео на мониторе).

## Устройство кода

| Файл | Что делает |
|---|---|
| `GlazokCam/Net/PeerSignaling.swift` | WebSocket к облаку PeerJS (0.peerjs.com) — тот же протокол, что у `peerjs.min.js` 1.5.4 |
| `GlazokCam/Net/PeerLink.swift` | WebRTC-соединение: канал управления (JSON) и видеозвонок |
| `GlazokCam/Net/IceConfig.swift` | TURN Metered из QR-кода, иначе STUN |
| `GlazokCam/Camera/CameraController.swift` | AVFoundation: фокус по точке, ручные настройки, объективы, зум |
| `GlazokCam/AppModel.swift` | Логика камеры — повторяет `index.html` (go-live / go-idle / viewer-add / manual-set / focus) |
| `GlazokCam/Views/*` | Экраны SwiftUI |
| `project.yml` | Описание проекта для XcodeGen |

Сборка на своём Mac: `brew install xcodegen && cd ios && xcodegen generate && open GlazokCam.xcodeproj`.
